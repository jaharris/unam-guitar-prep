UNAM Guitar Prep — GitHub Pages setup

This package is preconfigured for:
  GitHub username: jaharris
  Repository: unam-guitar-prep

Expected site URL:
  https://jaharris.github.io/unam-guitar-prep/

Expected RSS feed URL:
  https://jaharris.github.io/unam-guitar-prep/feed.xml

SETUP
1. On GitHub, create a PUBLIC repository named exactly:
   unam-guitar-prep

2. Upload feed.xml to the top level (root) of the repository.

3. Open the repository's Settings > Pages.

4. Under Build and deployment:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
   Click Save.

5. Wait for GitHub Pages to publish the site. GitHub will show the live URL.

6. Check this address in a browser:
   https://jaharris.github.io/unam-guitar-prep/feed.xml
   You should see XML text or a browser-rendered XML document.

7. In Apple Podcasts, choose Follow a Show by URL and enter:
   https://jaharris.github.io/unam-guitar-prep/feed.xml

IMPORTANT
- You are hosting only this small XML feed file on GitHub Pages.
- The audio files remain on the original publishers' servers; they are referenced by the feed.
- If a publisher changes an audio URL, that item in the feed may need to be updated.
- The repository needs to be public for GitHub Pages on a free GitHub account.
